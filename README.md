# 📅 My Pixel Calendar

A cozy, animated pixel‑art calendar featuring seasonal backgrounds, drifting snowflakes, smooth month navigation, and ambient audio.  
Built with **HTML, CSS, and JavaScript** to create an immersive, retro‑inspired experience.

---

## ✨ Features

- 📅 **Dynamic Calendar Rendering** — Automatically generates days for each month  
- ⏪⏩ **Month Navigation** — Switch between months with simple arrow buttons  
- ❄️ **Animated Snowfall** — Floating snowflakes for a cozy winter aesthetic  
- 🎞️ **Pixel‑Art Backgrounds** — Looping seasonal video for atmosphere  
- 🔊 **Ambient Audio Player** — Optional background sound for immersion  
- 🖥️ **Retro UI Elements** — Pixel‑art icons and interface details  
- 📱 **Responsive Layout** — Works on desktop and mobile  

---

## 🛠️ Technologies Used

### **Frontend**
- **HTML5** — Structure and layout  
- **CSS3** — Styling, animations, pixel‑art effects  
- **JavaScript (ES6+)** — Calendar logic, month switching, animations  

### **Media**
- **MP4 Video** — Background animation  
- **SVG / PNG** — Pixel‑art icons and snowflakes  
- **MP3 Audio** — Ambient sound loop  

---

## 🔧 Process Overview

- Designed the pixel‑art theme and cozy winter aesthetic  
- Built the calendar structure using **HTML + CSS Grid**  
- Implemented month switching and date generation in **JavaScript**  
- Added animated snowflakes using CSS and keyframes  
- Integrated a looping background video for atmosphere  
- Added an audio player for optional ambient sound  
- Ensured the layout works across different screen sizes  

---

## ⚠️ Challenges Faced

- 📅 **Generating accurate month layouts** (handling leap years, month lengths, offsets)  
- ❄️ **Animating snowflakes smoothly** without affecting performance  
- 🎞️ **Layering video + pixel‑art elements** while keeping everything readable  
- 📱 **Maintaining responsiveness** with many overlapping visual elements  
- 🔊 **Balancing audio controls** so they don’t disrupt the UI  
- 🎨 **Keeping the pixel‑art aesthetic consistent** across assets
